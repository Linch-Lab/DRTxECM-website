驗證下載檔（選用）

在命令提示字元執行（檔名請換成你下載的那一個）：

certutil -hashfile DRTxECM-win64.zip SHA256
certutil -hashfile DRTxECM-python.zip SHA256

把輸出與 SHA256SUMS.txt 的內容比對，一致即表示檔案完整未被修改。

安裝方式

  1. 解壓 DRTxECM-win64.zip 到任意資料夾（例如 C:\Tools\DRTxECM）
  2. 執行 DRTxECM.exe
  3. 首次啟動需要解壓與載入函式庫，會比之後慢一些（數秒到十數秒）
  4. 匯入 EIS 資料即可開始，操作流程見 使用說明

請先完整解壓再執行，不要直接在 ZIP 壓縮檔裡面雙擊執行檔。 Windows 的「壓縮資料夾」會讓程式無法正確讀取同資料夾的函式庫。

從原始碼執行（macOS / Linux）

打包好的免安裝版目前只提供 Windows。macOS 與 Linux 使用者可以從原始碼執行， 需要 Python 3.10 與幾個科學計算套件： 

git clone https://github.com/Linch-Lab/DRTxECM.git
cd DRTxECM
pip install numpy scipy pandas matplotlib scikit-learn cvxopt PyQt5 click
python launch.py

完整說明（含沒有 git 時改用 ZIP 下載）請見 INSTALL.md。

下載疑難

點了按鈕卻沒有開始下載？

按鈕連到 GitHub Releases 的檔案。若你的網路環境阻擋 GitHub， 可以改用 Releases 頁面手動選擇檔案， 或使用 proxy。

Windows 顯示「不明的發行者」或 SmartScreen 警告？

因為本專案未購買程式碼簽章憑證。這是所有免費開源軟體的共同情況，並非病毒。 你可以：點「更多資訊」→「仍要執行」；或自行從原始碼建置， 以確保執行檔與原始碼一致。也可以用上面的 SHA256 驗證下載檔。

防毒軟體誤判？

PyInstaller 打包的執行檔偶爾會被誤判。本專案的建置流程刻意關閉了 UPX 壓縮 （UPX 會明顯提高誤判率）。可先驗證 SHA256，或自行從原始碼建置。

解壓後執行卻跳出「找不到 xxx.dll」？

通常是沒有完整解壓就執行，或是解壓過程被中斷。請刪除整個資料夾重新解壓一次。

出現「Windows 無法存取指定的裝置、路徑或檔案」？

這代表 Windows 在啟動程式前就把它擋住了，不是程式本身出錯。 本程式沒有購買程式碼簽章憑證，因此學校或公司的電腦有可能依政策阻擋未簽章的 執行檔。請依序試：

  1. 對 ZIP 檔按右鍵 →「內容」→ 勾選「解除封鎖」→ 確定，然後才解壓。 這樣一次解除全部檔案的「已封鎖」標記。已經解壓了才處理的話， 進到資料夾全選檔案 → 右鍵 → 內容 → 勾「解除封鎖」。
  2. 檢查防毒軟體的隔離區，確認 DRTxECM.exe 是不是被隔離了。
  3. 改解壓到 C:\DRTxECM——短路徑、本機磁碟、不同步雲端。 （Windows 路徑上限 260 字元，本程式內部最長路徑 100 字元， 所以解壓所在的資料夾要短於約 159 字元。）
  4. 如果資料夾在 OneDrive 裡，確認檔案不是「僅線上」的佔位檔案： 對資料夾按右鍵 →「永遠保留在此裝置上」。

還是不行嗎？發行檔裡附了一支 診斷.cmd，雙擊即可。 它會檢查檔案完整性、路徑長度、封鎖標記（並可選擇解除）、 AppLocker／WDAC 等會阻擋未簽章程式的政策，以及防毒狀態與偵測紀錄。 把輸出整段貼到 GitHub Issues 就能很快定位問題。同一資料夾的「使用前必讀.txt」有完整說明。

如果這是學校或公司的電腦，很可能是資訊單位強制執行「只允許簽章過的程式」 （AppLocker／WDAC）。這種情況程式無法自行繞過，需要請資訊單位把 DRTxECM 加入允許清單，或改用個人電腦。診斷.cmd 的 [4] 區段會顯示這類政策。
