在命令提示字元執行：

安裝方式

  1. 解壓 DRTxECM-win64.zip 到任意資料夾（例如 C:\Tools\DRTxECM）
  2. 執行 DRTxECM.exe
  3. 首次啟動需要解壓與載入函式庫，會比之後慢一些（數秒到十數秒）
  4. 匯入 EIS 資料即可開始，操作流程見 使用說明

請先完整解壓再執行，不要直接在 ZIP 壓縮檔裡面雙擊執行檔。 Windows 的「壓縮資料夾」會讓程式無法正確讀取同資料夾的函式庫。

從原始碼執行（macOS / Linux）

打包好的免安裝版目前只提供 Windows。macOS 與 Linux 使用者可以從原始碼執行， 需要 Python 3.10 與幾個科學計算套件： 

git clone https://github.com/Linch-Lab/DRTxECM.git
cd DRTxECM
pip install numpy scipy pandas matplotlib scikit-learn cvxopt PyQt5 click
python launch.py

完整說明（含沒有 git 時改用 ZIP 下載）請見 INSTALL.md。

下載疑難

點了按鈕卻沒有開始下載？

按鈕連到 GitHub Releases 的檔案。若你的網路環境阻擋 GitHub， 可以改用 Releases 頁面手動選擇檔案， 或使用 proxy。

Windows 顯示「不明的發行者」或 SmartScreen 警告？

因為本專案未購買程式碼簽章憑證。這是所有免費開源軟體的共同情況，並非病毒。 你可以：點「更多資訊」→「仍要執行」；或自行從原始碼建置， 以確保執行檔與原始碼一致。也可以用上面的 SHA256 驗證下載檔。

防毒軟體誤判？

PyInstaller 打包的執行檔偶爾會被誤判。本專案的建置流程刻意關閉了 UPX 壓縮 （UPX 會明顯提高誤判率）。可先驗證 SHA256，或自行從原始碼建置。

解壓後執行卻跳出「找不到 xxx.dll」？

通常是沒有完整解壓就執行，或是解壓過程被中斷。請刪除整個資料夾重新解壓一次。
